- **所有回答匿名**。問卷不要求登入，不收集 Email 或帳號，除非妳自願在最後一段留下聯絡方式。

- **抽獎聯絡方式**只用於本次抽獎及得獎通知，開獎日起 20 天內刪除。
- 公布得獎名單時只顯示部分遮蔽的聯絡方式，例如 `@abc***` 或 `ab***@gmail.com`。
- 所有資料不會提供給第三方，也不會用於上述以外的用途。
- 回覆透過 Google 表單儲存在團隊自己的帳號中。
